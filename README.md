# Precision Enchanting (Fabric, Minecraft 26.3)

Стол точного зачарования: держите предмет/книгу в основной руке, ПКМ по столу →
ползунки для каждого подходящего зачарования. Лазурит не нужен, оплата только уровнями опыта.

* Несовместимые зачарования автоматически снимаются при выборе нового.
* Многие зачарования можно поднять выше ванильного максимума (голубая цифра).
* Понижение/снятие уровней бесплатно (можно убрать проклятия).
* Баланс — в `EnchantRules.java` (POWER_DIVISOR, OVERCAP_STEP, таблица EXTENDED).
* Рецепт: 2 пузырька опыта, книга, 2 алмаза, обычный стол зачарований, 3 обсидиана.

## Сборка
Нужны Java 25 и Gradle 9.5.1 (или gradlew из fabric-example-mod):

    gradle build        # или ./gradlew build

Jar: `build/libs/precision-enchanting-1.0.0.jar` (не `-sources`).

Без установки: залейте папку в GitHub — workflow `.github/workflows/build.yml`
соберёт jar во вкладке Actions → Artifacts.
